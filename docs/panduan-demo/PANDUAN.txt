PANDUAN EFA — ALUR IMPOR TERBARU

1. Buka https://efa.madgo.my.id/app. Buat akun uji/ruang usaha baru agar tidak mengubah data demo bersama.
2. Buka Impor CSV. Ada slot Penjualan dan Mutasi bank. Boleh mengisi salah satu, atau keduanya.
3. Untuk skenario backend terbaru, pilih 03-demo-penjualan-bersih.csv pada Penjualan dan 04-demo-mutasi-bersih.csv pada Mutasi bank. Jangan mencampur pasangan file ini dengan 01/02 pada percobaan yang sama.
4. Tekan Periksa file. Baca jumlah baris, nominal, duplikat dan warnings. Peringatan baris debit dilewati bukan berarti impor gagal.
5. Setelah pratinjau sesuai, tekan Simpan file yang sudah diperiksa. Aplikasi menyimpan penjualan lebih dahulu, lalu mutasi bank. Lihat jumlah baris tersimpan, pasangan otomatis, pasangan AI dan baris dilewati. AI dapat bernilai 0; frontend tidak menghubungi AI.
6. Buka Verifikasi. Pasangan yang sudah tersimpan otomatis tidak memerlukan persetujuan lagi. Tunai lunas dan penerimaan non-operasional tidak masuk antrean.
7. Pilih kartu yang tersisa. Baca alasan, sisa, kategori dan saran biaya. Tekan Periksa dan setujui, periksa kedua sisi serta nominal, baru simpan. Saran biaya belum disetujui sampai kamu menekan Simpan pasangan.
8. Untuk kandidat ambigu, pilih sendiri lawannya. Penerimaan gabungan bisa dialokasikan bertahap ke beberapa penjualan; jangan menghitung uang yang sama dua kali.
9. Buka Riwayat untuk jejak keputusan dan Laporan untuk unduh rekap CSV. Rekap hasil bukan perhitungan laba bersih dan bukan format impor mentah.
10. Jika lupa sandi, pilih Lupa kata sandi pada halaman masuk. Buka tautan email, buat sandi baru dan konfirmasi, lalu login ulang. Jangan membagikan tautan reset.
11. Untuk memulai latihan kosong, pemilik membuka Pengaturan > Kosongkan data workspace. Unduh rekap dulu jika diperlukan. Isi password dan ketik HAPUS. Transaksi/impor/alokasi dihapus permanen; akun dan audit tetap ada. Jangan mencoba ini pada workspace bersama.

FORMAT YANG DIPAKAI
- Penjualan sederhana: tanggal,referensi,nama,nominal,kanal.
- Tanggal, nama/keterangan, nominal dan kanal perlu tersedia. Referensi boleh kosong, tetapi referensi membantu pencocokan. ID dibuat server; tidak perlu diketik pada template sederhana.
- Mutasi bank mengikuti header CSV bank yang didukung. Kredit adalah uang masuk, debit dilewati, saldo bukan nominal transaksi.
- Hanya CSV UTF-8. Simpan ulang Excel sebagai CSV; unggahan XLSX/PDF/gambar belum didukung.
- File 01-penjualan.csv dan 02-penerimaan.csv adalah latihan format kanonik lama yang tetap bisa diproses. INV-102 dapat langsung cocok otomatis setelah kedua file disimpan; jangan mencari kartu yang sudah selesai di antrean Verifikasi.
- PBL_WEEK2_POINTS.csv adalah daftar pekerjaan, bukan transaksi. umkm-rekap.csv adalah hasil ekspor, bukan template impor.

JIKA ADA KENDALA
- Salah satu file gagal disimpan: baca hasilnya, file yang sudah sukses tidak perlu diulang; retry memproses file yang belum sukses.
- Sesi berakhir: masuk kembali dan pilih ulang file; draft file tidak disimpan lintas sesi.
- Antrean gagal dimuat: muat ulang. Itu tidak berarti semua transaksi cocok.
- Hitungan demo mengikuti data awal workspace dan konfigurasi backend. Gunakan workspace kosong untuk membandingkan hasil yang bisa diulang.
