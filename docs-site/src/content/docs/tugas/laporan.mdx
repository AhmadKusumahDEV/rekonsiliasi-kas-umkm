## Tujuan

Mengunduh catatan beserta status dan sisa alokasinya. Laporan EFA adalah rekap rekonsiliasi, bukan laporan laba bersih atau laporan keuangan lengkap.

## Sebelum mulai

- Pastikan impor dan keputusan terakhir selesai diproses.
- Izinkan browser mengunduh file dan siapkan aplikasi spreadsheet.

## Langkah

1. Buka **Laporan**.
2. Baca penjualan, penerimaan, penjualan belum teralokasi, dan sudah cocok.
3. Lihat jumlah pasangan aktif dan biaya yang sudah dikonfirmasi. Jangan menganggap seluruh penerimaan sebagai laba.
4. Tekan **Unduh rekap CSV**. Mengunduh tidak mengubah transaksi.
5. Buka `umkm-rekap.csv` di spreadsheet. Periksa jenis, tanggal, referensi, nominal, sisa, dan status.
6. Gunakan filter tanggal di spreadsheet bila membutuhkan periode tertentu. Halaman Laporan saat ini memakai seluruh data usaha.
7. Simpan salinan sesuai kebutuhan dan batasi siapa yang boleh mengakses data tersebut.

## Error umum

- **Unduhan belum muncul:** periksa daftar unduhan dan izin browser. Jika sesi berakhir, masuk kembali lalu unduh.
- **Sisa dianggap rugi:** ini nilai yang belum terpasang, bukan kesimpulan kehilangan uang.
- **Rekap berbeda dari filter Transaksi:** laporan memakai seluruh data. Filter tampilan tabel bukan filter ekspor.
