## Tujuan

Memasukkan penjualan dan uang masuk dari file CSV atau Excel (.xlsx). Memeriksa file belum mengubah catatan; penyimpanan dilakukan setelah kamu menyetujuinya.

## Sebelum mulai

- Siapkan CSV UTF-8 atau XLSX. File XLS lama, PDF, foto, dan workbook terenkripsi belum didukung.
- Penjualan memakai tanggal, nama, nominal, kanal; referensi boleh kosong.
- File maksimal 10 MB dan workbook maksimal 20 sheet. Hasil konversi tetap dibatasi 1 MB CSV dan 500 baris data.

Untuk latihan, pakai [CSV penjualan simulasi](/panduan/examples/penjualan.csv) dan [CSV mutasi simulasi](/panduan/examples/mutasi-bank.csv) pada akun latihan. Ini file yang dipakai video, bukan data usaha nyata.

## Langkah

1. Buka menu **Impor CSV** di aplikasi. Menu ini juga menerima Excel (.xlsx).
2. Pilih file pada slot **Penjualan**. Gunakan **Unduh template penjualan** jika perlu contoh.
3. Pilih file penerimaan pada slot **Mutasi bank**. Salah satu slot boleh kosong; jangan masukkan mutasi ke slot Penjualan.
4. Tekan **Periksa file**. Jika pemilih sheet muncul, pilih satu sheet lalu tekan **Periksa sheet**. Tunggu pratinjau selesai; nama sheet dan baris header ditampilkan bila tersedia.
5. Periksa tanggal, nama, nominal, jumlah baris siap, total, dan **Periksa peringatan ini**. Baris debit bukan uang masuk; saldo bukan nominal transaksi.
6. Tekan **Simpan file yang sudah diperiksa** hanya jika benar. Penjualan disimpan lebih dulu. Jika file kedua gagal, hasil file pertama tetap tersimpan; periksa pesan sebelum mencoba file yang gagal lagi.
7. Baca **baris tersimpan**, **pasangan otomatis**, **pasangan AI**, dan **dilewati** secara terpisah. Buka **Verifikasi** untuk keputusan yang tersisa. Angka AI dapat bernilai 0; itu tidak berarti impor gagal. Baca catatan status AI di bawah hasil. Jika AI gagal, hasil aturan tetap tersimpan; lanjutkan ke Verifikasi.

## Error umum

- **“Pilih minimal satu file CSV atau XLSX.”** Isi salah satu slot, lalu periksa lagi.
- **File Excel tidak bisa dibaca:** buka di spreadsheet, lepas perlindungan sandi, lalu simpan ulang sebagai XLSX. Mengganti nama ekstensi tidak mengubah format file.
- **Perlu memilih sheet:** pilih satu sheet yang berisi transaksi. Gunakan **Pilih sheet lain** jika pratinjau belum sesuai.
- **413 / file terlalu besar:** kurangi ukuran workbook atau pecah data. File mentah 10 MB tetap harus menghasilkan CSV maksimal 1 MB dan 500 baris.
- **0 baris siap / debit dilewati:** baca peringatan. Pilih laporan yang memuat uang masuk; jangan memakai saldo rekening sebagai penerimaan.
- **Satu file gagal disimpan:** jangan mengimpor ulang file yang sudah berhasil. Lihat hasil per slot; file yang berhasil tidak dikirim ulang saat melanjutkan penyimpanan yang sama.
- **Baris melebihi batas:** pecah file. Batas yang ditampilkan aplikasi berasal dari akun/server, bukan janji angka tetap di panduan.
