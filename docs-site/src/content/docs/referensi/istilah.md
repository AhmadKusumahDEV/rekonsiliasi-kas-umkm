| Istilah | Arti sehari-hari |
| --- | --- |
| Rekonsiliasi / cocokkan kas | Menelusuri hubungan penjualan dengan uang masuk |
| Penjualan | Nilai barang atau jasa yang terjual; belum tentu sudah diterima |
| Penerimaan | Uang masuk yang dicatat; tidak sama dengan laba |
| Sisa tagihan | Nilai penjualan yang belum terpasang atau dijelaskan |
| Alokasi | Memakai sebagian atau seluruh penerimaan untuk menjelaskan penjualan |
| Biaya / fee | Potongan yang perlu bukti dan konfirmasi; tidak menambah uang diterima |
| Workspace / ruang kerja | Tempat catatan satu usaha, terpisah dari usaha lain |
| Referensi | Nomor yang membantu menghubungkan dua catatan |
| Pratinjau / preview | Pemeriksaan sebelum data disimpan |
| Audit / Riwayat | Catatan siapa melakukan apa dan kapan |
| Pencairan / settlement | Dana yang dilepas penyedia menurut jadwalnya |
| CSV / unggah / upload | File teks tabel yang diimpor; Excel XLSX juga bisa diunggah langsung |
